# llama.cpp's CUDA build needs cudart/cublas DLLs. This project borrows
# PyTorch's bundled copies at runtime (retail_llm/llm.py adds torch/lib to the
# DLL search path), so install BOTH from their CUDA wheel indexes:
#
#   python -m venv .venv && .venv\Scripts\activate
#   pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu124
#   pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cu124
#
# CPU-only fallback (slower, no torch needed):
#   pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
#
# PIN 0.3.4: newer prebuilt wheels (0.3.35) are compiled with AVX-512 and crash
# with WinError 0xc000001d on Alder Lake CPUs (i7-12650H etc. — AVX-512 fused
# off). 0.3.4's wheel is AVX2-only and runs fine.
